Tips dari Kisi-Kisi Resmi
PENTING
01
Hafal docs.aws.amazon.com! Saat lomba, hanya boleh buka dokumentasi AWS resmi. Latihan cari informasi di sana, bukan Google.
02
Gunakan email baru! Email peserta tidak boleh terafiliasi dengan AWS Academy manapun. Siapkan email khusus lomba.
03
Kuasai 3 tool utama: Terraform (IaC), GitHub Actions (CI/CD), dan Postman (API testing) — semua ada di kisi-kisi dan wajib dikuasai.
04
Fokus Serverless (40 pts!): Modul 2 paling besar nilainya. Lambda + API Gateway + DynamoDB harus sangat dikuasai.
05
Naming convention penting! Contoh soal: bucket name format LKSSEP2020partisipantname. Ikuti format yang diminta soal dengan tepat.
06
IAM LabRole: Di AWS Learner Lab, kamu tidak bisa buat IAM user baru. Semua resource gunakan LabRole. Latihan dengan constraint ini!
